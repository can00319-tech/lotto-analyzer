# 🎱 로또 6/45 분석·조합 스튜디오

동행복권 로또 6/45 역대 당첨번호를 자동으로 모아 **통계 분석**, **조건 필터 조합**,
**비너스 추첨기 방식 시각 추첨**, **매일 추천 기록 관리**를 한 화면에서 제공하는
Streamlit 웹앱입니다.

> ⚠️ 모든 조합의 1등 확률은 **1 / 8,145,060** 으로 완전히 같습니다.
> 이 앱의 통계와 점수는 **참고용 지표**이며 당첨을 보장하지 않습니다.
> 구매는 여유 자금 범위에서 재미로만 즐겨 주세요.

---

## 1. 설치

파이썬 3.10 이상이 필요합니다.

```bash
cd lotto-analyzer
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## 2. 실행

```bash
streamlit run app.py
```

브라우저가 자동으로 열립니다. 열리지 않으면 터미널에 표시되는 주소
(기본 `http://localhost:8501`)를 직접 여세요.

포트를 바꾸려면: `streamlit run app.py --server.port 8600`

## 3. 화면 구성

| 탭 | 내용 |
|---|---|
| 📊 **역대 통계** | 1~45 번호별 출현 빈도(보너스 포함 토글), 최근 N회 핫/콜드 번호, 홀짝·고저·총합 분포, 최근 5회 당첨번호 |
| 🎯 **조건 조합기** | 고정수·제외수, 홀짝 개수, 고저 개수, 총합 구간, 연속번호 최대 허용, 역대 1등 완전 중복 제외, 기존 추천 중복 제외 → 새 조합 생성·자동 저장·적합도 표시 |
| 🎱 **추첨기** | 45개 공이 통에서 섞이다 하나씩 나오는 비너스 추첨기 스타일 캔버스 연출(실제 난수 기반) |
| 📅 **추천 기록** | 생성일·대상 회차별 기록, 모드/오늘 필터, CSV 다운로드, 선택 삭제 |

### 점수 지표 읽는 법

- **분포 적합도(0~100)** — 역대 당첨번호 분포와 얼마나 닮았는지.
  총합(±12 구간 밀도, 가중 34%) + 홀짝 개수(33%) + 고저 개수(33%)의 상대 점수.
- **생일 회피 지수(0~100)** — 32~45 번호의 비중. 생일(1~31)로 번호를 고르는 사람이
  많아, 높은 번호가 많을수록 당첨 시 동점자가 줄어드는 경향이 있습니다.
  역대 당첨번호에서 32~45가 차지한 비중은 약 31%입니다.
- 두 지표 모두 **당첨 확률을 높이지 않습니다.** 참고용입니다.

## 4. 데이터

| 경로 | 설명 |
|---|---|
| `data/seed_draws.json` | 내장 기본 데이터(1~1250회차, 2026-11-14 기준). 처음 실행할 때 `draws.json`으로 복사됩니다. |
| `data/draws.json` | 로컬 캐시. 앱의 모든 분석은 이 파일을 기준으로 동작합니다. |
| `data/history.json` | 추천 기록(생성 시각·대상 회차·번호·점수·필터). CSV로 내려받을 수 있습니다. |
| `data/meta.json` | 마지막 자동 확인 시각(1시간에 한 번만 서버를 확인합니다). |

### 수집 방식

- 앱을 열면 **1시간에 한 번** 최신 회차를 조용히 확인합니다(실패해도 앱은 그대로 동작).
- 사이드바 **🔄 최신 회차 업데이트** — 최신 회차만 받아 증분 추가.
- 사이드바 **📥 전체 데이터 다시 받기** — 1회차부터 전부 다시 받아 캐시 재생성.
- 동행복권은 공식 API를 제공하지 않습니다. 앱은 사이트가 쓰는 아래 주소를 사용합니다.
  - 최신 회차: `https://www.dhlottery.co.kr/lt645/selectPstLt645Info.do`
  - 지정 회차 ±10회차: `…/lt645/selectPstLt645InfoNew.do?srchDir=center&srchLtEpsd={회차}`
  - 전 회차: `…/lt645/selectPstLt645Info.do?srchLtEpsd=all`
  - (2026년 사이트 개편 전 주소 `common.do?method=getLottoNumber` 는 더 이상 JSON을 주지 않습니다.)

사이트 개편으로 응답 형식이 바뀌면 다음 증상이 나타납니다: `JSON 대신 HTML 응답` 안내,
`응답 형식이 예상과 다름`. 이때는 캐시 데이터로 앱이 계속 동작하고, 사이드바 안내를 보고
잠시 후 다시 시도하면 됩니다.

### 네트워크가 막힌 환경

인터넷이 없어도 **내장 데이터(1250회차)** 로 모든 분석·조합·추첨 기능을 쓸 수 있습니다.
업데이트 버튼만 "연결하지 못했습니다" 안내를 보여 주고, 나머지는 그대로 동작합니다.

## 5. 클라우드 배포 — 구글 시트에 기록 저장

Streamlit Community Cloud처럼 파일이 다시 배포될 때 초기화되는 환경에서는
`data/history.json`이 사라집니다. 배포판은 추천 기록을 **구글 시트**에 남기도록 바꿀 수 있습니다.

1) 구글 시트(`로또 분석기 추천 기록`)와 Apps Script 웹 앱을 준비합니다.
   - 시트 탭 `기록`, 1행 헤더: `created_at, target_round, mode, numbers, score_json, filters_json`
   - `Code.gs`가 비밀 토큰(`GSHEET_TOKEN`)을 검증하고 `doGet`(전체 행 JSON 반환)·`doPost`(헤더+행 전체 덮어쓰기)를 처리
   - `배포 > 새 배포 > 유형: 웹 앱`(실행 주체: 나, 액세스 권한: 모든 사용자) → `https://script.google.com/macros/s/.../exec`
2) Streamlit Cloud의 `Settings > Secrets`에 두 값을 넣고 앱을 재시작합니다.

```toml
GSHEET_WEBAPP_URL = "https://script.google.com/macros/s/.../exec"
GSHEET_TOKEN = "웹 앱 Code.gs와 같은 토큰"
```

동작 방식:

- 두 값이 없으면 예전처럼 `data/history.json`을 씁니다(PC 로컬 실행은 그대로).
- 시트 모드는 세션에 60초 캐시를 두어 위젯을 조작할 때마다 네트워크를 왕복하지 않고,
  저장·삭제가 성공하면 캐시를 바로 갱신합니다.
- 웹 앱 호출이 실패하면 안내 문구만 보여 주고 앱은 캐시(없으면 빈 목록)로 계속 동작합니다.
- 사이드바에 현재 저장소(`구글 시트 연동 중` / `로컬 파일`)가 표시되고,
  시트 모드에서는 `🔄 시트에서 기록 새로고침` 버튼이 생깁니다.

## 6. 검증

```bash
python3 -m py_compile app.py     # 문법 검사
python3 test_app.py              # Streamlit AppTest 스모크 테스트(임시 폴더 사용)
```

`test_app.py`는 실제 `app.py`를 임시 데이터 폴더에서 실행해 다음을 확인합니다.

1. 첫 실행 시 데이터 로드·캐시 생성, 최신 회차 표시
2. 통계 화면 차트·표 렌더링, 최근 N회 슬라이더 변경
3. 고정수/총합 조건으로 조합 생성 → 조건 충족·기록 저장·기존 기록과 중복 없음
4. 추첨기 결과 생성·재추첨·기록 저장
5. 기록 화면 CSV 다운로드, 기록 삭제
6. 캐시 파일이 손상돼도 내장 데이터로 자동 복구
7. 구글 시트 모드(가짜 웹 앱 대역) — `구글 시트 연동 중` 표시, 저장 POST, 캐시 사용,
   새 세션에서 시트 기록 읽기, 연결 실패 시 안내

## 7. 폴더 구조

```
lotto-analyzer/
├── app.py                 # 앱 본체(단일 파일)
├── requirements.txt
├── README.md
├── test_app.py            # AppTest 스모크 테스트
└── data/
    ├── seed_draws.json    # 내장 기본 데이터
    ├── draws.json         # (첫 실행 후 생성) 로컬 캐시
    ├── history.json       # (추천 저장 후 생성) 기록
    └── meta.json          # (자동 확인 후 생성) 동기화 시각
```

데이터 폴더를 다른 곳에 두려면 환경 변수로 지정할 수 있습니다.

```bash
LOTTO_DATA_DIR=/path/to/data streamlit run app.py
```
